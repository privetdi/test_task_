# Замер скорости скачивания

Python 3.10+, без сторонних зависимостей. Скрипт делает 10 последовательных
GET-запросов к HTTP(S) URL и полностью читает каждый ответ.

## Запуск

Из корня репозитория:

```bash
python3 -m net_speed "https://example.com/image.jpg"
```

Замените URL на прямую ссылку на файл. Таймаут сетевой операции по умолчанию
30 секунд; изменить его можно аргументом `--timeout 15`.

Скрипт выводит среднее время запроса, общий объём скачанных тел ответов в байтах
и скорость в **MB/s**: 1 MB = 1 000 000 байт.
Скорость = общий объём / суммарное время запросов / 1 000 000.
Время включает соединение, ожидание ответа и чтение тела целиком.
Результат зависит от выбранного сервера. При ошибке замер останавливается.

## Тесты

```bash
python3 -m unittest discover -v
```

Тесты используют локальный HTTP-сервер, доступ в интернет не нужен.
